# CPU Overview

## 1. What is CPU?

CPU (Central Processing Unit) là bộ xử lý trung tâm của máy tính.

CPU thực hiện các lệnh và xử lý dữ liệu từ hệ điều hành,
phần mềm và các thiết bị phần cứng khác.

---

## 2. Main CPU Specifications

| Specification | Description |
|---|---|
| Manufacturer | Nhà sản xuất |
| Product Family | Dòng CPU |
| Model | Mã CPU |
| Generation | Thế hệ CPU |
| Architecture | Kiến trúc |
| Socket | Socket CPU |
| Cores | Số nhân |
| Threads | Số luồng |
| Base Clock | Xung nhịp cơ bản |
| Boost Clock | Xung nhịp tối đa |
| Cache | Bộ nhớ đệm |
| TDP | Công suất thiết kế nhiệt |
| Integrated Graphics | GPU tích hợp |
| Memory Support | RAM hỗ trợ |
| PCIe Support | Chuẩn PCIe hỗ trợ |

---

## 3. CPU Cores

Core là nhân xử lý vật lý của CPU.

Ví dụ:

Intel Core i5-10400:

- 6 Cores
- 12 Threads

---

## 4. CPU Threads

Thread là luồng xử lý.

Nhiều CPU có công nghệ cho phép mỗi core xử lý nhiều thread.

---

## 5. CPU Clock Speed

### Base Clock

Xung nhịp cơ bản của CPU.

### Boost Clock

Xung nhịp CPU có thể đạt được khi điều kiện hoạt động cho phép.

---

## 6. CPU Cache

CPU Cache là bộ nhớ tốc độ cao nằm gần hoặc bên trong CPU.

Các cấp phổ biến:

- L1 Cache
- L2 Cache
- L3 Cache

---

## 7. CPU Socket

Socket là chuẩn kết nối giữa CPU và motherboard.

Ví dụ:

- LGA1200
- LGA1700
- AM4
- AM5

---

## 8. Integrated Graphics

Một số CPU có GPU tích hợp.

Ví dụ:

Intel Core i5-10400
→ Intel UHD Graphics 630

CPU có hậu tố F của Intel thường không có GPU tích hợp.
