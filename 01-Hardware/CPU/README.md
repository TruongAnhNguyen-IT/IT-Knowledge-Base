# CPU

> **Central Processing Unit (CPU) – Bộ xử lý trung tâm**

CPU là thành phần chính chịu trách nhiệm thực hiện các lệnh, xử lý dữ liệu và điều khiển các hoạt động tính toán của hệ thống máy tính.

**English:**  
The CPU (Central Processing Unit) is the primary processor responsible for executing instructions, processing data, and performing computational tasks in a computer system.

Sau khi hoàn thành phần này, có thể:

- Hiểu Base Clock và Boost Clock.
- Hiểu CPU Cache.
- Hiểu CPU Socket.

- Thực hiện quy trình troubleshooting cơ bản.

After studying this section, you should be able to:

- Understand what a CPU is.
- Understand CPU specifications.

- Check CPU and motherboard compatibility.

- Diagnose common CPU problems.
