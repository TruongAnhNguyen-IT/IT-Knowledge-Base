# Laptop Overview / Tổng quan về Laptop

## 1. What is a Laptop? / Laptop là gì?

**Tiếng Việt**

Laptop là máy tính cá nhân có thiết kế nhỏ gọn, có thể sử dụng bằng pin và dễ dàng di chuyển.

Một laptop thường tích hợp:

- CPU
- GPU
- RAM
- SSD/HDD
- Motherboard
- Display
- Keyboard
- Touchpad
- Battery
- Wi-Fi
- Bluetooth
- Webcam
- Microphone
- Speaker
- Cooling system

**English**

A laptop is a portable personal computer designed to operate using a battery and be easily transported.

A typical laptop integrates:

- CPU
- GPU
- RAM
- SSD/HDD
- Motherboard
- Display
- Keyboard
- Touchpad
- Battery
- Wi-Fi
- Bluetooth
- Webcam
- Microphone
- Speaker
- Cooling system

# 3. CPU / Bộ xử lý

CPU thực hiện các tác vụ tính toán và xử lý lệnh.

Các thông số quan trọng:

- Model
- Generation
- Cores
- Threads
- Base Clock
- Boost Clock
- Cache
- Power characteristics

**English:**

The CPU performs computational tasks and executes instructions.

Important specifications include:

- Model
- Generation
- Cores
- Threads
- Base Clock
- Boost Clock
- Cache
- Power characteristics

---

# 4. GPU / Bộ xử lý đồ họa

Laptop có thể sử dụng:

### Integrated GPU

GPU tích hợp trong CPU hoặc SoC.

### Dedicated GPU

GPU rời với bộ nhớ đồ họa riêng hoặc thiết kế bộ nhớ riêng tùy nền tảng.

GPU rời thường xuất hiện trên:

- Gaming laptops
- Workstations
- Content creation laptops

---

# 5. RAM / Bộ nhớ

RAM là bộ nhớ tạm thời được sử dụng khi hệ điều hành và ứng dụng đang chạy.

Các thông số:

- Capacity
- Type
- Speed
- Channels
- Soldered / SO-DIMM
- Maximum supported capacity

Các loại phổ biến:

- DDR4
- DDR5
- LPDDR4X
- LPDDR5
- LPDDR5X

---

# 6. Storage / Lưu trữ

Laptop có thể sử dụng:

- 2.5-inch SATA HDD
- 2.5-inch SATA SSD
- M.2 SATA SSD
- M.2 NVMe SSD

NVMe SSD thường sử dụng giao tiếp PCIe.

---

# 7. Display / Màn hình

Các thông số quan trọng:

- Screen size
- Resolution
- Refresh rate
- Panel type
- Brightness
- Color coverage
- Response time
- Touch support

Ví dụ:

```text
15.6"
1920 × 1080
IPS
144 Hz
```

---

# 8. Battery / Pin

Pin cung cấp năng lượng khi laptop không kết nối AC adapter.

Thông số thường gặp:

- Voltage
- Capacity
- Watt-hour (Wh)
- Battery health
- Cycle count

---

# 9. AC Adapter / Bộ sạc

Bộ sạc cung cấp nguồn điện cho laptop và có thể đồng thời sạc pin.

Thông tin cần kiểm tra:

- Output Voltage
- Output Current
- Output Power
- Connector
- USB-C Power Delivery support nếu có

Công suất:

```text
Power (W) = Voltage (V) × Current (A)
```

Ví dụ:

```text
19.5V × 3.33A ≈ 65W
```

# 10. Cooling System / Hệ thống tản nhiệt

Hệ thống tản nhiệt thường gồm:

- Fan
- Heatsink
- Heat pipe
- Vapor chamber trên một số thiết kế

Mục đích:

- Transfer heat
- Maintain operating temperature
- Prevent thermal throttling

# 13. Laptop Form Factors / Kiểu thiết kế

### Traditional Laptop

Laptop dạng truyền thống.

### Ultrabook / Thin and Light

Thiết kế mỏng nhẹ.

### Gaming Laptop

Thiết kế cho hiệu năng cao và GPU rời.

### Workstation Laptop

Tập trung vào workload chuyên nghiệp.

### 2-in-1

Có thể chuyển đổi giữa laptop và tablet.

Không phải mọi laptop đều có khả năng nâng cấp giống nhau.
