# Laptop

> **Laptop Computer – Máy tính xách tay**

Laptop là một hệ thống máy tính di động tích hợp nhiều thành phần phần cứng như CPU, RAM, storage, display, keyboard, touchpad, battery, wireless adapter và các thiết bị ngoại vi khác trong một thiết bị nhỏ gọn.

**English:**

A laptop is a portable computer system that integrates multiple hardware components such as the CPU, RAM, storage, display, keyboard, touchpad, battery, wireless adapter, and other peripherals into a compact device.

# 🎯 Learning Objectives / Mục tiêu học tập

Sau khi hoàn thành phần Laptop, có thể:

- Hiểu cấu trúc phần cứng của laptop.
- Nhận biết các linh kiện chính.
- Kiểm tra tình trạng laptop trước khi bàn giao hoặc mua bán.
- Kiểm tra CPU, RAM và storage.

- Kiểm tra keyboard và touchpad.
- Kiểm tra pin và bộ sạc.
- Kiểm tra Wi-Fi và Bluetooth.

- Ghi nhận tình trạng thiết bị một cách có hệ thống.

**English:**

After completing this section, you should be able to:

- Understand laptop hardware architecture.
- Identify major laptop components.

- Test CPU, RAM, and storage.
- Inspect the display.
- Test the keyboard and touchpad.
- Check the battery and charger.
- Test Wi-Fi and Bluetooth.
- Perform basic laptop maintenance.
- Check RAM and storage upgrade options.

- Document device condition systematically.
